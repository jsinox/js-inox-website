# JS INOX — Website corporativo

Landing page corporativa responsiva em Astro + TypeScript + CSS, com prévia HTML offline.

## Prévia rápida
1. Baixe ou clone o repositório.
2. Abra `preview.html` no navegador.
3. Teste navegação, FAQ e formulário de demonstração.

## Desenvolvimento
Requisitos: Node.js 20.3+ e npm.

```bash
npm install
npm run dev
```

Para validar e gerar a saída estática:
```bash
npm run check
npm run build
```

## Escopo e limitações
- O site apresenta categorias divulgadas pela JS INOX: soluções em aço inox, estruturas e soluções metálicas e projetos sob medida.
- Categorias publicadas no Instagram não são tratadas como comprovação automática de capacidade operacional.
- A seção de projetos aguarda imagens autorizadas e informações validadas.
- O formulário é demonstrativo: valida localmente, sem envio, transmissão ou armazenamento.
- Não há integração de WhatsApp, e-mail, CRM, analytics ou rastreamento.
- Não há deploy configurado nem publicação automática.
- As logos estão em WebP otimizado para reduzir o peso dos assets, preservando o desenho visual; os arquivos enviados originalmente permanecem disponíveis no pacote ZIP de entrega.
- A denominação complementar da marca segue pendente de aprovação.

Consulte `RELATORIO-VALIDACAO.md`, `TESTES-MANUAIS.md` e `docs/` para documentação, verificações e pendências.
